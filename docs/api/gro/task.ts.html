InvokeTask
#

task.ts view source

InvokeTask import type {InvokeTask} from '@fuzdev/gro/task.js';

Invokes a task by name with Gro's task resolution, so local overrides of builtins apply.

Names are checked against TaskRegistry and args against the named task's Args schema input. A name widened to string (dynamic, a path, or a directory) opts out with loose Args.
