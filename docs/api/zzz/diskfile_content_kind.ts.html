ReadonlySet<string>

type ReadonlySet<string>

import {AUDIO_EXTENSIONS} from '@fuzdev/zzz/diskfile_content_kind.js';

Extensions viewed as audio. Each is one the backend serves with a media type (twin of media_content_type in zzz_server's file_bytes.rs), so an <audio> element can play it from the byte route. webm is here because that's what a recording is; a .webm holding video plays as its audio track.
